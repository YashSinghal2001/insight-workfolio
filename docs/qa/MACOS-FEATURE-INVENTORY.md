# macOS desktop app: feature inventory (reference for Windows parity)

Date: 2026-11-13. Source: code in `apps/desktop` on branch `deploy/hostinger-vps` (desktop code as of commit `4d66269`), read only. Nothing was built, run or launched for this inventory. Prior runtime evidence is taken from `docs/master-checklist.md`, `docs/development-plan.md`, `docs/status/DESKTOP-CROSS-PLATFORM-READINESS.md` and `docs/qa/MACOS-IDLE-AND-SCREENSHOT-TESTS.md` and was checked against the code.

Paths: `rs/` = `apps/desktop/src-tauri/src/`, `ts/` = `apps/desktop/src/`, `test/` = `apps/desktop/test/`, `scripts/` = `apps/desktop/scripts/`. Rust tests are `module::test_name` in the same file.

Columns:
- **Platform-specific?** `macOS` = code under `#[cfg(target_os = "macos")]` (or macOS-only config); `unix` = `#[cfg(unix)]`; `shared` = same code on every OS; `shared + macOS adapter` = shared logic over a macOS OS call.
- **Changed since last native run?** The last native macOS run was `verify:native` 8/8 on 2026-10-19 (debug build, local API). `Yes` = behaviour changed after it (mostly commit `4d66269`, 2026-11-12), so that evidence no longer applies; `No` = unchanged; `New` = feature never covered by a native run.
